What we're proposing

The product type page is the table. Filters sit beside it, show how many parts each choice leaves, grey out choices that would leave none, and are written into the address so a filtered view can be bookmarked or sent to a colleague. Application is a filter here, not a separate copy of the catalogue, which is how the same part can sit under Steer-by-Wire and under Robotics without being published twice.

Why

The live Motor Position Sensors (2D) page does have a parametric table with a CSV export, which is good and worth keeping. It has no filters, though, the values are inconsistent ("3.7 V ~ 18 V" next to "3.7 to 18"), and the A33002 row links to the A33003 page.

Filters only work if the data behind them is clean, so the real work here is in the parts database rather than the page.
